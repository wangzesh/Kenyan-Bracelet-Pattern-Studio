# 5/6 Bead Lettering Reference

Source studied: `/Users/zeshenwang/Downloads/IMG_0349.HEIC`.

## Observations

- The bracelet letters are not drawn as full typography. They use a compact block-pixel style.
- The visible text is built on a 5-row letter core, even though the bracelet alternates 6-bead and 5-bead columns.
- Six-bead columns are not used to make taller letters. They usually add one extra background or border bead while the letter itself stays visually 5 rows tall.
- Beads appear directionally oriented: 6-bead columns use vertically oriented beads, while 5-bead columns use horizontally oriented beads.
- Strokes are heavy and simple: vertical strokes, top/bottom bars, and stair-step diagonals.
- Letter spacing is usually one mostly blank column.
- Border beads are counted inside the bracelet height; they are not extra rows.
- Border colour can continue through decorative sections, but text is more readable if the letter area stays mostly high-contrast foreground on background.

## Practical Rule For This Project

For narrow 5/6 bracelets:

1. Design letters as 5-row glyphs.
2. Convert 5-row glyph columns into the bracelet's 6/5 column sequence.
3. For 6-bead columns, add one background bead as padding instead of stretching the letter.
4. Keep decorative border colours around stars or symbols, but avoid forcing border stripes through small text unless the text remains readable.
5. Preview 6-bead columns as vertical ovals and 5-bead columns as horizontal ovals.
