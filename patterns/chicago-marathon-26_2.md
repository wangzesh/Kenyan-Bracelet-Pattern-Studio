# Chicago Marathon 26.2 Bracelet Pattern

Maker-ready deterministic bead grid.

## Summary

- Concept: Chicago colors -> red star -> `26.2` -> red star -> Chicago colors.
- Total columns: 63.
- Column heights: odd columns are 6 beads, even columns are 5 beads.
- Bead order in each column: top to bottom.
- Outer rim: none. Black is used only for the `26.2` numerals and decimal point.

## Legend

- `W`: white
- `C`: Chicago light blue
- `R`: red
- `K`: black

## Layout

- Columns 1-18: Chicago light-blue stripe field on white.
- Columns 19-23: red star motif.
- Columns 24-25: white spacer.
- Columns 26-37: `26.2` in black.
- Columns 38-40: white spacer.
- Columns 41-45: red star motif.
- Columns 46-63: Chicago light-blue stripe field on white.
