# Photo Bead Inventory Palette

Colour variations visible in the reference photo. Hex/RGBA values are approximate preview colours for the local renderer, not measured photo samples.

## Symbol Rules

- Use short symbols in pattern grids so columns stay readable.
- Numbered symbols are variants within the same colour family.
- `T` in the label means translucent.
- `CL` means clear/transparent.
